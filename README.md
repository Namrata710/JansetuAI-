# JanSetu AI 🇮🇳

JanSetu AI is an AI-inspired civic engagement platform designed to bridge the gap between citizens and public services. It provides an intuitive digital interface for navigating civic issues, exploring government schemes, and accessing citizen assistance.

## 🚀 Features

- **AI-Style Civic Search** – Explore civic services through an intuitive search interface.
- **Complaint Reporting Workflow** – A structured 3-step flow for reporting civic issues.
- **Civic Issue Categories** – Navigate different categories of civic problems.
- **Government Schemes & Benefits** – Explore information about schemes and citizen benefits.
- **Smart Chat Assistant** – An interactive assistant with intent-based responses.
- **Multilingual Interface** – English and Hindi language toggle.
- **Personalised Onboarding** – Welcome and onboarding experience.
- **Responsive UI** – Responsive dark-themed civic-tech interface.

## 🛠️ Tech Stack

- React
- JavaScript
- Vite
- Lucide React
- CSS

## 💻 Run Locally

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/YOUR_USERNAME/JanSetuAI.git
cd JanSetuAI
npm install
npm run dev
```
